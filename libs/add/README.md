# 🪄 @ng-doc/add

The `ng add` schematics that install NgDoc and configure your project.

It's part of [NgDoc](https://ng-doc.com/) 📚, the documentation engine for Angular projects.

[![NPM][npm-shield]][npm-url]
[![MIT License][license-shield]][license-url]

## 🚀 Getting started

Run it in your Angular project to install and configure NgDoc:

```bash
ng add @ng-doc/add
```
