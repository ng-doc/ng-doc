# Agent instructions

All agent guidance for this repository lives in one skill, `ng-doc-developer`, at
`.agents/skills/ng-doc-developer/`. Claude Code sees the same directory through the symlink
`.claude/skills/ng-doc-developer`.

**Before starting any task, read `.agents/skills/ng-doc-developer/SKILL.md` in full.** Then
read the files under `.agents/skills/ng-doc-developer/references/` that match the areas you
touch. The skill routes you to them.

Keep this file a pointer. Put new guidance in the skill, not here.
